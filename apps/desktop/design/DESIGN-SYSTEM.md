# Дизайн-система Meter

Фінальні токени (після WCAG-фіксів). Стиль: приладова панель — гострі кути (radius 0),
datasheet-структура з волосяних ліній, вермільйон лише як сигнал. Фронт кодиться строго за
цими значеннями.

## Колір

| Роль | Значення | Застосування |
| --- | --- | --- |
| ground | #E8EAE3 | основне тло |
| ground-alt | #DFE1D9 | чергування секцій |
| panel | #EFF0EA | підняті панелі в адмінці |
| ink | #1C1D19 | текст; темні поверхні (сайдбар, ledger); структурні лінії |
| ink-line | #33352E / #26271F | лінії на темному |
| text-secondary | #4C4F46 | вторинний текст на світлому |
| text-muted | #565951 | підписи/капшни на світлому (AA ≥ 4.5:1) |
| text-muted-dark | #8C8E83 / #9D9F94 | приглушений текст на темному |
| hairline | #C6C8BE / #D3D5CC | рамки й розділювачі |
| signal | #D6401A | графіка, заливки, великі числа (≥19px) |
| signal-text | #B5340F | дрібний вермільйон-текст і чипи зі світлим текстом (AA) |
| signal-on-dark | #F0613C | вермільйон на темному |

Правило: вермільйон = «потребує уваги / перевищення / HIGH». Ніколи як декор.

## Типографіка

- **Archivo** (400/500/600/700) — весь текст і заголовки. Кирилиці в Archivo немає, тож українські літери малює **Inter Tight** (лише кириличний піднабір): браузер бере латиницю з Archivo, кирилицю — з Inter Tight, у тому самому рядку.
- **IBM Plex Mono** (400/500/600) — лише дані: цифри, репозиторії, шляхи, id.

| Роль | Розмір | Вага | Трекінг |
| --- | --- | --- | --- |
| Display H1 | 60px | 700 | -0.035em |
| H2 | 38px | 700 | -0.03em |
| H3 | 19–22px | 600 | -0.02em |
| Body | 16–17px | 400 | 0 |
| Small | 13–14px | 400/500 | 0 |
| Data (mono) | 12–14px | 400/500 | 0 |

## Простір, рамки, радіус

- Крок: 4 / 8 / 12 / 16 / 20 / 24 / 28 px.
- Секції лендинга: padding 80px вертикаль, 64px горизонталь; контент адмінки 24–28px.
- **Радіус = 0.** **Тіней немає** — глибина через рамки (1px hairline або 1px #1C1D19), не box-shadow.

## Компоненти (стисло)

- **Button:** primary (ink-заливка, paper-текст); secondary (1px ink-контур); on-dark (paper-заливка).
  Hover: primary → #2A2C25. Focus: видимий ring 2px. Тач-таргет ≥ 44px.
- **Severity chip:** HIGH — заливка #B5340F, paper-текст; MED — контур ink; LOW — заливка #D8DAD0, текст #4C4F46.
  Розрізняються заливкою + підписом, не лише відтінком.
- **Sidebar item:** default #9D9F94 на ink; active — тло #2A2C25, paper-текст, ліва мітка 2px #D6401A.
- **Dropdown:** кнопка 1px ink-рамка, як поле; список під нею в тій самій рамці, рядки ≥44px з hairline,
  активний рядок — ink-заливка, paper-текст; обраний — галочка. Нативний `<select>` не використовуємо.
- **Діалог підтвердження:** панель 1px ink поверх скриму ink/60; фокус спершу на «Скасувати». Не `window.confirm`.
- **Підказка:** ink-плашка, mono 12px, paper-текст (на темному — навпаки). Не `title`.
- **Помилка поля:** рамка #B5340F і текст під полем #B5340F, словами інтерфейсу. Не браузерна бульбашка.
- **Data table / KPI / ledger:** одна рамка #1C1D19, внутрішні розділювачі hairline, цифри mono праворуч.
  Тренд: ▲ #B5340F (увага), ▼/стабільне — #565951.

## Тост і очікування

Тост — підсумок дії, сказаний один раз і окремо від контролу: «вийшло», «передано, чекаємо»,
«не вийшло». Помилка конкретного поля лишається під полем (див. «Помилка поля»); тост — для
результату, що стосується сторінки, або що настає, коли контролу вже нема (вебхук Paddle за
кілька секунд). Не замінює діалог підтвердження і не несе секрет, що показується раз.

- **Місце:** фіксовано знизу праворуч, відступ 24px; ширина 360px (не ширше екрана мінус 32px);
  стос знизу вгору з кроком 8px, найновіший унизу; не більше 4 — найстаріший іде першим.
  Той самий текст удруге не дублюється, а показується заново.
- **Вигляд:** ink-плашка (як підказка й сайдбар) — тло #1C1D19, текст paper 14px; радіус 0, тіней
  нема: на світлому тлі край дає сама заливка. Ліва мітка 2px, як у Notice й активного пункту
  сайдбару. Над текстом — роль словом, 13px uppercase, щоб стан не був лише відтінком.
- **Ролі:**
  | Роль | Мітка | Слово | Колір слова | Живе |
  | --- | --- | --- | --- | --- |
  | success | paper #EFF0EA | «Готово» | #9D9F94 | 5 с |
  | info | #8C8E83 | «До відома» | #9D9F94 | 5 с |
  | error | #F0613C (signal-on-dark) | «Помилка» | #F0613C | до закриття |
- **Час:** success/info зникають самі через ~5 с; поки на тості курсор чи фокус — таймер стоїть
  і після починається спочатку. Error лишається, доки його не закриють.
- **Закрити:** кнопка «×» праворуч, тач-таргет 44×44, `aria-label` «Закрити сповіщення»,
  #9D9F94 → paper на hover, focus-ring 2px #D6401A (≥3:1 на ink). Іншого контролу в тості нема.
- **Рух:** поява — 160ms, `cubic-bezier(0.2, 0, 0, 1)`, opacity 0→1 і зсув 8px знизу; зникнення
  без анімації. `prefers-reduced-motion: reduce` — без руху взагалі, тост просто зʼявляється.
- **A11y:** два постійні live-регіони, що є в DOM завжди, навіть порожні: success/info — у
  `aria-live="polite"`, error — у `aria-live="assertive"`, обидва `aria-relevant="additions"`
  (зникнення тосту не озвучується). Тост вставляється в уже наявний регіон — елемент із
  `role="status"`, вставлений одразу заповненим, деякі зчитувачі пропускають. Сам тост ролі не
  має, щоб не вкладати live-регіон у live-регіон (подвійне озвучення). Помилки стоять у стосі
  нижче за success/info. Текст тосту — словами інтерфейсу; відмову API — з мапи кодів помилок.
- **Очікування (Pending):** коли сторінка чекає підтвердження від когось іншого (вебхук Paddle
  після оплати чи зміни місць), на місці — рядок як Notice (ліва мітка 2px ink, текст
  #4C4F46, `role="status"`, `aria-busy`), перед ним квадрат 8px ink, що «дихає» (opacity
  1→0.25, 1.2 с). Без спінера, без вермільйону — нічого не зламано. Коли сторінка перестає
  питати сервер, квадрат зникає, речення лишається. Reduced motion — квадрат нерухомий. Форма,
  що чекає, вимкнена цілком (`fieldset disabled`) — повторне натискання не спише вдруге.
  Успіх чи «ще не підтверджено» після очікування — тостом.

## Accessibility

- Контраст: текст ≥ 4.5:1, великий (≥19px) ≥ 3:1, графіка ≥ 3:1.
- Стан/важливість кодуються колір + підпис/форма, не лише відтінком.
- Додати в коді: focus-ring 2px на всіх інтерактивних; тач-таргети ≥44px; сегментні перемикачі як `<button>`.
