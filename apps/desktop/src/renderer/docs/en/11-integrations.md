# Integrations

| Integration | What it gives you |
|---|---|
| **GitHub** (Settings → GitHub) | Sign in with GitHub (the Vibe Teamlead GitHub App) and the repository is filled from `origin`. Signing in and giving the app access are two steps: after signing in, install the app on GitHub (**Install the app on GitHub**) and choose all repositories or only some; without it the app can't see private repositories, and the setup dialog says so with a button to fix it. To add a repository later: https://github.com/settings/installations → the Vibe Teamlead app → add the repository, then **Check again**. A personal access token is only needed when the App isn't installed on the repository's account or organisation, or to act as another account. Issues → tasks, PRs, PR review. The base branch and "push new branches" are available even without connecting GitHub. |
| **GitLab** | The same for GitLab: issues and merge requests. |
| **Linear** | Task sync and Linear MCP for agents. |
| **draw.io** | Architecture diagrams open in draw.io with one button. |
| **IDE / terminal** | Open a worktree in your editor or terminal (Settings → Developer Tools). |
