# Інтеграції

| Інтеграція | Що дає |
|---|---|
| **GitHub** («Налаштування → Проєкт → GitHub») | Вхід через GitHub (GitHub App Vibe Teamlead), репозиторій підставляється з `origin`. Вхід і доступ застосунку — два окремі кроки: після входу встановіть застосунок на GitHub (**Установити застосунок на GitHub**) і виберіть усі репозиторії або лише деякі; без цього застосунок не бачить приватних репозиторіїв, і діалог налаштування про це каже з кнопкою, щоб виправити. Щоб додати репозиторій пізніше: https://github.com/settings/installations → застосунок Vibe Teamlead → додайте репозиторій, потім **Перевірити ще раз**. Персональний токен потрібен, лише якщо App не встановлено в акаунті чи організації репозиторію або треба діяти від іншого акаунта. Issues → задачі, PR, рев'ю PR. Базова гілка й «пушити нові гілки» доступні й без підключення GitHub. |
| **GitHub Actions** | CI у сайдбарі: запуски проєкту наживо, що заважає CI проходити, секрети. Застосунок пушить main (і гілки задач у приватних репозиторіях) токеном GitHub App (див. «CI»). |
| **GitLab** | Те саме для GitLab: issues і merge requests. |
| **Linear** | Синхронізація задач і Linear MCP для агентів. |
| **Telegram** | Ваш власний бот на телефоні: відповідайте на питання, перевіряйте й зливайте, затверджуйте дизайн, додавайте задачі, зупиняйте команду (див. «Telegram»). |
| **draw.io** | Діаграми архітектури відкриваються в draw.io однією кнопкою. |
| **IDE / термінал** | Відкрити worktree у вашому редакторі чи терміналі («Налаштування → Developer Tools»). |
