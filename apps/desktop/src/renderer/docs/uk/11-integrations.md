## GitHub

### Вхід і доступ

- Вхід через GitHub (GitHub App Vibe Teamlead), репозиторій підставляється з `origin`.
- Вхід і доступ застосунку — два окремі кроки.
- Після входу встановіть застосунок на GitHub (**Установити застосунок на GitHub**) і виберіть усі репозиторії або лише деякі.
- Без цього застосунок не бачить приватних репозиторіїв, і діалог налаштування про це каже з кнопкою, щоб виправити.

### Додати репозиторій пізніше

- Відкрийте https://github.com/settings/installations.
- Виберіть застосунок Vibe Teamlead і додайте репозиторій.
- Потім натисніть **Перевірити ще раз**.

### Персональний токен

- Персональний токен потрібен, лише якщо App не встановлено в акаунті чи організації репозиторію або треба діяти від іншого акаунта.

### Що це дає

- Issues → задачі, PR, рев'ю PR.
- Базова гілка й «пушити нові гілки» доступні й без підключення GitHub.
