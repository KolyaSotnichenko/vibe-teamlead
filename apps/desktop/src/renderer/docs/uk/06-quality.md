# Якість і безпека

| Шар | Що робить |
|---|---|
| **TDD + AC** | Кожна вимога має тест; QA перевіряє, що тест справді її тримає. |
| **gitleaks** | Секрети в коді блокують схвалення. |
| **OSV-Scanner** | Вразливі залежності блокують схвалення. |
| **Semgrep** | Статичний аналіз змінених файлів (ін'єкції, небезпечні API; правила його реєстру рівня ERROR) блокує схвалення. Працює лише якщо Semgrep встановлено (`brew install semgrep` або `pip install semgrep`); інакше, або коли правила не вдається завантажити, гейт пропускається і звіт про це каже. Якщо Semgrep не зміг розібрати частину файлів або повідомив про помилку самого запуску, звіт каже «CLEAR (PARTIAL: …)», а вкладка «Безпека» називає, що не було охоплено, щоб ви переглянули ці файли самі; якщо він не зміг просканувати жодного файлу, гейт вважається таким, що не спрацював. |
| **Дизайн-перевірка** | Статична перевірка доданих рядків UI на токени дизайн-системи + рев'ю скріншотів (див. «Дизайн-система і Storybook»). |
| **Браузерна перевірка** | QA відкриває застосунок у Chrome (Playwright / DevTools MCP), робить скріншоти й дивиться консоль. |
| **Strix** | Пентест у Docker (опційно). |
| **Хуки безпеки** | Межі шляхів, allowlist команд, заборона вбивати процеси самого застосунку. |
| **Ізоляція оточення** | Агенти працюють з власною конфігурацією Claude Code (`~/.vibe-teamlead/claude-code`), а не з вашою `~/.claude`. Змінні оточення фільтруються. |

Сканери (gitleaks, OSV-Scanner), Claude Code, CodeGraph, Superpowers і Mermaid вбудовані в застосунок і нічого не треба ставити окремо. Semgrep не вбудований (це Python-пакет): встановіть його, якщо хочете цей гейт. Docker і Chrome потрібні лише для Strix і браузерних перевірок. Стан усіх інструментів видно в «Налаштування → Інструменти».
