# Обмеження і що варто знати

- **Слабші моделі** (через шлюз) гірше дотримуються інструкцій і можуть не відмітити чекбокси спеки. Для архітектури, планування й QA краще сильніші моделі.
- **Чи питає агент CodeGraph, залежить від моделі**, а не від її сили: у логах двох проєктів (1398 сесій) деякі моделі питали в більшості сесій, а одна жодного разу. Тому застосунок сам шукає файли, з якими працює сесія, а останній рядок логу кожної сесії каже, скільки разів питав агент.
- **Не закривайте кришку, поки працюють агенти.** Комп’ютер уві сні прокидається лише на мить, тож агенти майже не просуваються, а робота після паузи коштує дорожче, бо кеш моделі вже застарів. Застосунок скаже, коли це сталося.
- **Strix навантажує процесор**, поки працює контейнер. Це нормально, після завершення Docker прибирається.
- **PR потребує GitHub `origin`**; злиття працює і без нього.
- **Windows (бета): проєкти всередині WSL** (`\\wsl$\…`, `\\wsl.localhost\…`) поки не підтримуються, і застосунок не додає такий проєкт. Тримайте проєкт на диску Windows, наприклад `C:\Users\you\projects`.
- **Windows (бета): інсталятор не підписаний.** SmartScreen попереджає під час першого запуску (Докладніше → Все одно виконати). Агентам і перевіркам застосунку потрібен Git for Windows; «Налаштування → Інструменти» показує його й пропонує `winget install --id Git.Git -e`.
- **Одна копія застосунку на користувача.** Повторний запуск виводить відкрите вікно наперед.
- **Підписку Claude** вмикайте лише на власному комп'ютері. Ліміти спільні з вашим звичайним використанням Claude.
