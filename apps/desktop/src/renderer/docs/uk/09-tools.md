# Інструменти агентів: MCP і скіли

| Що | Для чого |
|---|---|
| **Інструменти Vibe Teamlead** (`mcp__vibe-teamlead__*`) | Статус підзадач, прогрес збірки, запис відкриттів і підводних каменів, статус QA, пам'ять (`search_memory`, `remember`), рендер діаграм (`render_diagram`: draw.io/Mermaid → PNG). |
| **CodeGraph** (`mcp__codegraph__*`) | Карта коду. |
| **Context7** | Актуальна документація бібліотек (хостований HTTP-сервер). Допомагає не писати за застарілим API. Опційно з ключем `CONTEXT7_API_KEY`. |
| **Браузер** (Playwright / Chrome DevTools MCP) | QA перевіряє UI. Запускається лише тоді, коли задача змінила UI-файли. |
| **Electron MCP** | QA для Electron-застосунків. |
| **Linear** | Робота із задачами Linear (якщо підключено). |
| **Власні MCP-сервери** | Додаються в MCP Overview і призначаються агентам. |
| **Мовні сервери** | Кодер і QA-фіксер отримують інструмент `LSP` і діагностику типів після кожної правки (див. «Мовні сервери» нижче). |
| **GSAP skills** (вбудований плагін) | Офіційні скіли GSAP від GreenSock (MIT) для дизайнера й UI-кодерів проєкту, що анімує через GSAP. Сама бібліотека GSAP не вбудована (див. «Дизайн перед кодом»). |
| **draw.io skill** (вбудований плагін) | Дає архітектору формат діаграм draw.io. |
| **Superpowers** (вбудований плагін) | Набір скілів Claude Code: TDD, дебаг, планування тощо. |
| **frontend-design** (вбудований плагін) | Скіл frontend-design від Anthropic (Apache-2.0), що завантажується для підзадач кодера, які зачіпають UI (див. «frontend-design» нижче). |
| **UX-рев'ю** (вбудований плагін) | Рев'юер QA задачі, що змінила UI-файли, перевіряє змінені сторінки в браузері (див. «UX-рев'ю» нижче). |
| **Скіл architecture** | Стандарт документа архітектури, діаграм і циклу перевірки для архітектора. |

## Подробиці

### Мовні сервери

- Вбудовані: TypeScript/JavaScript через typescript-language-server, Python через pyright. З машини: gopls, rust-analyzer, clangd, якщо встановлені.
- Кодер і QA-фіксер отримують інструмент `LSP` (перехід до визначення, посилання, hover) і діагностику типів одразу після кожної правки, тож не запускають увесь typecheck, щоб побачити помилки.
- Які сервери отримує сесія, залежить від мов проєкту: з `project_index.json` або сканування package.json / pyproject.toml / go.mod / Cargo.toml.
- Журнал задачі каже `LSP: typescript, python` або чому серверів немає.
- Вбудовані сервери працюють на Node, що постачається з CodeGraph.
- Перемикач: «Налаштування → Агенти».

### frontend-design

- Це скіл frontend-design від Anthropic (Apache-2.0).
- Його отримує кодер, коли підзадача зачіпає UI-файли (`.tsx`, `.css`, `.vue` …) або не називає файлів у проєкті з інтерфейсом.
- Підзадачі з API чи даними його не завантажують.
- Дизайн-система проєкту і спек мають пріоритет.
- Скіл відповідає за ієрархію, розкладку, тексти й те, щоб інтерфейс не виглядав шаблонним.

### UX-рев'ю

Рев'юер QA задачі, що змінила UI-файли, відкриває змінені сторінки в браузері (Playwright).

#### Що він перевіряє

- Сторінки на ширині 375 і 1280 пікселів.
- Сторінки з клавіатури.
- Сторінки в темній темі, якщо вона є в дизайн-системі.
- Їхні порожній, завантажувальний і помилковий стани.
- Як людина до них дістається.

#### З чим він звіряє

- З Web Interface Guidelines від Vercel (MIT).
- З чеклистами audit та harden з Impeccable (Apache-2.0).
- Дизайн-система і спек мають пріоритет.

#### Що блокує схвалення

- Проблема, через яку людина не може користуватися сторінкою, блокує схвалення.
- Питання смаку йдуть у «UX notes» у звіті.
- Задачі без змін інтерфейсу його не завантажують.
