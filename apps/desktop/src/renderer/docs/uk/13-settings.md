# Налаштування — шпаргалка

| Розділ | Що там |
|---|---|
| **Вигляд / Відображення / Мова** | Тема (світла/темна/системна), масштаб, мова (українська/англійська). |
| **Інструменти розробника** | IDE і термінал для «відкрити в…», YOLO-режим для ручних терміналів. |
| **Шрифти термінала** | Шрифти терміналів. |
| **Claude** | Режим доступу (API-ключ / підписка), ключі, base URL, перевірка з'єднання. |
| **Vercel** | Акаунт Vercel для розгортань: **Підключити Vercel** — вхід у браузері (першого разу застосунок завантажує Vercel CLI, близько 180 МБ), або вставте токен. Показує акаунт і його команди; **Відключити** прибирає вхід з цього Mac. |
| **Інструменти** | Стан вбудованих і зовнішніх інструментів (сканери, Chrome, Docker, Strix, CodeGraph). |
| **Агенти** | Профіль моделей, моделі фаз і функцій, Архітектор (для кожної задачі / лише для складних / ніколи), Форматувати й лінтити після кожної правки (власні prettier/ESLint, Biome, ruff чи gofmt проєкту на кожному файлі, який пише кодер; типово увімкнено), Мовні сервери для агентів (вбудовані сервери TypeScript і Python, gopls/rust-analyzer/clangd, якщо встановлені; типово увімкнено, вимкніть на дуже великих репозиторіях, якщо бракує пам'яті), Security QA (Strix). |
| **Пам'ять** | Увімкнути/вимкнути, модель ембеддингів. |
| **Шляхи / Оновлення / Сповіщення / Діагностика й журнали** | Шляхи, оновлення, сповіщення, логи для діагностики. |
| **Проєкт → Загальні** | Модель агентів проєкту, CLAUDE.md, сповіщення. |
| **Проєкт → GitHub / GitLab / Linear** | Репозиторій, токен, базова гілка, пуш гілок, синхронізація issues. |
| **Майстер налаштування** | Перший запуск: Claude, інструменти, Dev Tools, приватність, пам'ять, облікові записи (необов'язкові входи в GitHub і Vercel; якщо пропущено, підключіть їх пізніше в Проєкт → GitHub і Налаштування → Vercel або на вкладці «Деплой»; вихід із кроку скасовує вхід, що триває). GitHub — це два кроки: вхід, а потім установлення застосунку Vibe Teamlead на GitHub і вибір репозиторіїв, якими він може користуватися; майстер просить зробити другий крок і перевіряє знову, коли ви повертаєтеся. Щоб додати репозиторій пізніше, відкрийте https://github.com/settings/installations, виберіть застосунок Vibe Teamlead і додайте його. Можна запустити знову. |

## Оновлення

Застосунок сам завантажує оновлення. Потім він перезапускається після 10-секундного відліку, який можна зупинити кнопкою **Пізніше**; відкладене оновлення встановиться, коли ви закриєте застосунок. Поки працюють агенти, застосунок чекає, доки вони закінчать, бо перезапуск зупинив би їх.
