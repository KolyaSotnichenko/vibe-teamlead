# Деплой

«Деплой» у сайдбарі (гаряча клавіша Y) показує, що відбувається з кодом проєкту після того, як його запушено: запуски GitHub Actions його репозиторію наживо і те, куди код вийшов у продакшн.

## Запуски

Останні запуски GitHub-репозиторію проєкту перелічено ліворуч. Виберіть один, і праворуч відкриється його граф: джоби workflow, згруповані в етапи за їхніми `needs`. Джоби, які не залежать одне від одного, стоять в одному етапі; ті, що на них чекають, йдуть у наступному.

Статус живий. Вигляд оновлюється кожні 5 секунд, поки щось виконується, і кожні 60 секунд в інший час. Оновлення йде лише поки «Деплой» відкритий і вікно видиме.

Клацніть джоб, щоб побачити його кроки, які оновлюються, поки він виконується. Лог з'являється, коли джоб завершиться. GitHub зберігає логи обмежений час, тож для старого запуску може бути написано, що GitHub більше не зберігає його лог; **Повний лог на GitHub** відкриває його там.

## Деплой і посилання на продакшн

Етап **Деплой** і посилання **Продакшн** беруться з GitHub Deployments, а не з workflow. Хостинг, який звітує в GitHub, наприклад Vercel через інтеграцію з GitHub, з'являється там зі своїм статусом і логом. Якщо ніхто не повідомляє про деплої, граф показує лише джоби workflow.

## Що потрібно

- **Вхід у GitHub.** Якщо його немає, у вікні є кнопка **Під'єднати GitHub**.
- **Репозиторій проєкту на GitHub.** Без нього вікно про це каже.
- **Нові дозволи, підтверджені один раз.** Дозволи застосунку в GitHub тепер включають читання Actions і Deployments. GitHub просить підтвердити їх один раз: відкрийте https://github.com/settings/installations, виберіть застосунок Vibe Teamlead і прийміть запит. Для цього у вікні є посилання **Керувати доступом на GitHub**.

## Коли щось не так

- **Застосунок не може читати Actions репозиторію:** дозволи вище ще не підтверджено, або застосунок не має доступу до цього репозиторію.
- **Ліміт запитів GitHub вичерпано:** вікно робить паузу до часу, який показує, і далі продовжує саме.
- **GitHub не відповідає:** вікно каже про це й пробує ще раз.

## Що далі

Налаштування хостингу, перевірка готовності та перегляди з'являться в наступних версіях «Деплою». Сьогодні він лише читає з GitHub і нічого не змінює.
